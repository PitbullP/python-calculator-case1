# Консольный калькулятор с историей операций

Итоговый проект по программе «Python-разработчик с использованием инструментов ИИ». Выполнен по **Кейсу № 1**.

## 📖 Описание проекта
Это консольное приложение на Python, которое выполняет базовые математические операции, сохраняет историю вычислений в текстовый файл и позволяет просматривать её прямо в программе. Программа защищена от ошибок ввода и деления на ноль.

## ⚙️ Функционал
В проекте реализованы все 7 задач из кейса:
1. Сложение, вычитание, умножение и деление двух чисел.
2. Поддержка как целых, так и десятичных чисел (с очисткой лишних нулей).
3. Сохранение истории операций в файл `history.txt`.
4. Просмотр истории вычислений через меню программы.
5. Валидация ввода (защита от ввода букв вместо цифр) с помощью ИИ (DeepSeek).
6. Обработка ошибок (защита от деления на ноль).
7. Удобное консольное меню с 6 пунктами.

## 🛠 Технологии
* **Язык:** Python 3.14.6
* **Среда разработки:** Visual Studio Code
* **Контроль версий:** Git, GitHub
* **ИИ-ассистент:** Веб-версия DeepSeek (для генерации кода валидации)
